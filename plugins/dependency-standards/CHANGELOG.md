# Changelog

## 0.1.0 - 2026-08-09

- Added a blocking intake gate for new dependencies covering need,
  alternatives, real usage and maintenance health, provenance, license,
  supply-chain exposure, and pinning and exit control.
- Added a lighter review gate for version updates, including bot-authored and
  security updates, and a removal rule for unused dependencies.
- Added ecosystem evidence for npm, GitHub Actions, container images, Python,
  Go, Rust, system packages, and fetched binaries, plus license classes and a
  committed dependency-record shape.
- Added positive, failure, and unsafe acceptance scenarios.
