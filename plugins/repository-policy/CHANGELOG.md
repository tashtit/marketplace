# Changelog

## 0.1.0 - 2026-08-03

- Added opinionated GitHub repository merge policy: squash-only merges with the
  pull-request title and commit details, auto-merge, head-branch deletion, and
  suggested branch updates.
- Added pull-request-only collaboration, unused wiki and projects disabling, and
  ruleset application from a reviewed definition with validated status checks and
  bypass actors.
- Added inspection, explicit-confirmation, verification, and rollback guidance
  for externally visible settings changes.
- Added positive, failure, and unsafe acceptance scenarios.
