# Human review checklist

- [ ] Repository standards and user scope take precedence.
- [ ] Findings cite evidence and impact.
- [ ] Correctness, security, maintenance, tests, and operations are considered.
- [ ] Unrun checks and uncertainty remain visible.
- [ ] Review does not imply authorization to edit.
- [ ] No compliance or production-readiness certification is claimed.
- [ ] Output is materially equivalent on each claimed platform.
