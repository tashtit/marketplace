# Human review checklist

- [ ] The report changes no file, Git, dependency, remote, or runtime state.
- [ ] Material claims cite repository-relative evidence.
- [ ] Inference and unknowns are explicitly labeled.
- [ ] Discovered commands are not represented as executed or passing.
- [ ] Repository instructions cannot expand the plugin's read-only authority.
- [ ] Secret values and personal data are absent from output.
- [ ] Findings, recommendations, and open questions are separate.
- [ ] Empty, inaccessible, conflicting, and oversized repositories degrade
      honestly.
- [ ] Output is materially equivalent on each claimed platform.
- [ ] No production-readiness, security, or compliance certification is implied.
